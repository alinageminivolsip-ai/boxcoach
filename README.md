# BoxCoach 🥊

Тренерский таймер для боксёров — PWA-приложение для работы на телефоне без интернета.

## Возможности

- ⏱ **Таймер** с поддержкой категорий: Взрослые (18+), Юниоры (15–17), Мастера (40+)
- ♂♀ **Раздельные настройки** по полу (количество и длительность раундов по правилам бокса)
- 🔊 **8 встроенных звуков** (гонг, свисток, звуки поддержки — синтез через Web Audio)
- 🎙 **Запись голоса** прямо в приложении с визуализацией волны
- 🎵 **Загрузка MP3/WAV/OGG/M4A** файлов (до 10 МБ каждый), хранятся в браузере
- ⚙️ **Гибкие настройки**: время раундов, отдыха, сигналы, подготовка, громкость
- 📴 **Офлайн-режим** через Service Worker
- 💾 **Все данные** сохраняются локально (localStorage/IndexedDB)

## Установка на телефон (как приложение)

### Android (Chrome)
1. Открой сайт в Chrome
2. Меню → «Добавить на главный экран»
3. Готово — работает как нативное приложение

### iOS (Safari)
1. Открой сайт в Safari
2. Кнопка «Поделиться» → «На экран Домой»
3. Готово

## Деплой на GitHub Pages

1. Загрузи все файлы в репозиторий
2. Settings → Pages → Source: `main` / `root`
3. Приложение будет доступно по адресу `https://USERNAME.github.io/REPO/`

## Правила бокса (встроены)

| Категория   | Пол     | Раунды | Время раунда | Отдых |
|-------------|---------|--------|--------------|-------|
| Взрослые    | Муж.    | 3      | 3:00         | 1:00  |
| Взрослые    | Жен.    | 4      | 2:00         | 1:00  |
| Юниоры      | Муж.    | 3      | 2:00         | 1:00  |
| Юниоры      | Жен.    | 3      | 2:00         | 1:00  |
| Мастера 40+ | Муж.    | 3      | 2:00         | 1:00  |
| Мастера 40+ | Жен.    | 3      | 2:00         | 1:00  |

Все параметры можно изменить вручную в настройках.

## Требования

- Современный браузер с поддержкой Web Audio API
- Для записи голоса: разрешение на микрофон
- HTTPS (обязательно для PWA и микрофона)
